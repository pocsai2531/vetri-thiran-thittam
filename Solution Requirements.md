## Functional Requirements
| FR No. | Functional Requirement (Epic) | Sub Requirement (Story / Sub-task) |
|---|---|---|
| FR-1 | User Registration | Sign up with email and password, set monthly income |
| FR-2 | Expense Management | Add, edit, delete expenses; upload CSV; auto-categorize each expense |
| FR-3 | Budget Planning | AI generates a monthly budget split by category and savings goal |
| FR-4 | Recommendations | Personalized saving tips and cheaper alternatives based on spending pattern |
| FR-5 | Insights | Dashboard charts, next-month spending forecast, overspending alerts |
| FR-6 | Reports | Download monthly summary report as PDF or CSV |

## Non-Functional Requirements
| NFR No. | Non-Functional Requirement | Description |
|---|---|---|
| NFR-1 | Usability | Simple screens that a first-time user can operate without training |
| NFR-2 | Security | Passwords hashed, user financial data stored per account and encrypted in transit |
| NFR-3 | Reliability | Graceful fallback when the AI service is unavailable |
| NFR-4 | Performance | Recommendations returned within 5 seconds |
| NFR-5 | Availability | Application available at least 99 percent of the time |
| NFR-6 | Scalability | Supports growth in users through a cloud deployment |
